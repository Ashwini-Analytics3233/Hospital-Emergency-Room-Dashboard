Hospital Emergency Room Dashboard

Project Description

A tutorial-based Excel Emergency Room Dashboard practice project created to analyze hospital emergency room data using Power Query and Excel dashboard features.

Key Metrics

- Number of Patients
- Average Wait Time
- Patient Satisfaction Score
- Admission Status

Key Analysis

- Patient Attend Status
- Gender-wise Analysis
- Patients by Age Group
- Patient Department Referral

Tools Used

- Microsoft Excel
- Power Query
- Pivot Tables
- Charts
- Slicers

Project Features

- Data cleaning and transformation using Power Query
- Interactive dashboard
- Monthly analysis
- Patient and department analysis
- Visual charts and graphs
